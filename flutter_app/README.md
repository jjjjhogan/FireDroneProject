# AeroScout Sim

A Flutter web prototype for the FireDrone/AeroScout Sim project. It turns the design preview into an interactive dashboard for wildfire patrol planning, drone fleet monitoring, scenario browsing, analytics, and live simulation controls.

## Run

```bash
flutter pub get
flutter run -d chrome
```

## Test

```bash
flutter analyze
flutter test
flutter build web
```

Scenario and hero visuals use generated wildfire patrol landscape images stored in `assets/images/`.
